Images show the first 10,000 steps from a blank tape in the Default space-time view, fitted to a 400 × 500 canvas. Time runs downward; horizontal position is tape position. Gray cells show the tape, black is unvisited space, and red/green mark head movement. These finite pictures illustrate the machines; the Rocq proofs establish nonhalting.
